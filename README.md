Overview

The SIMAD University Portal Admin is a web app for managing all content shown on the official SIMAD University Mobile App. Admins can create, update, and delete news, facilities, departments, schools, staff, and more — ensuring the mobile app stays up-to-date.

Features

Manage university data and media with ease

Secure login with JWT and role-based access

Upload and preview images via AWS S3 integration

Responsive, user-friendly interface

Real-time updates synced with the mobile app backend

Tech Stack

React.js (frontend)

Axios for API requests

JWT for authentication

React FilePond for file uploads

Connected to Node.js/Express API backend

Getting Started

Clone the repo:
git clone https://github.com/binAbdalla-shakra/simad-web-portal.git
cd simad-web-portal

Install dependencies:
npm install

Start the app:
npm start
Open http://localhost:3000 in your browser
